We follow the following guidelines regarding AI-assisted contributions:

- **AI Tools Welcomed**: We encourage you to use AI to help you design,
  read and write code and documents, as long as quality does not suffer.
  In short, use AI to help you do good work fast, but no slop.

- **Responsibility**: Humans must fully understand every single line of code.
  First and foremost, it is the code author's responsibility to make sure
  the code is correct, easy to understand, and high quality. Do not shift
  this responsibility to code reviewers or AI tools.

- **No Huge Changes**: It is a good engineering practice to do small and
  fast-paced changes. Each change list should be logical cohesive. If a
  function takes hundreds of lines of code, you should try to break it down
  into smaller functions.

- **Disclosure**: All AI usage in any form must be disclosed. You must declare
  the tools used (such as Claude Code, OpenAI Codex, Google Antigravity, Cursor,
  etc.) and how you used them in your code commit message.

These rules are not set in stone. We will continue to evolve them as AI
technologies mature and we gain more experience with AI tools.
